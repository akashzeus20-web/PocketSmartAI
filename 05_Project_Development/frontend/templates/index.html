PocketSmart AI is engineered with full deterministic fallback mechanisms. If an external AI API key is not supplied or quota is exceeded, the application transparently leverages its built-in market heuristic models so workflows never fail.

Backend Engine: Python 3.11 + FastAPI (Async)
AI Model: Google Gemini 1.5 Flash (Vision & Text)
Persistence: SQLite + SQLAlchemy ORM
Security: BCrypt Hashing + JWT Bearer Tokens
